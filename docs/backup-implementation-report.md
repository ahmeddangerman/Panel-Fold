# Portable library backup implementation

`LibraryRepository.exportBackup(prefs: SharedPreferences): ByteArray` exports metadata and settings as UTF-8 JSON. `LibraryRepository.importBackup(bytes: ByteArray, prefs: SharedPreferences): BackupImportResult` validates and merges an import. Both suspend functions run on `Dispatchers.IO`. The result exposes `summary`, `importedComics`, `pendingComics`, and `collections` for the root SAF UI. The public `BackupLimits.MAX_BYTES` is 5 MiB; the UI must also bound its input stream before constructing the byte array.

The version-one document identifies itself as `tablet-comics-library`. It contains reading position and page count, reading/discovery timestamps, favorite/finished state, page bookmarks, named collections (including empty collections), collection memberships, global user settings, and per-comic settings. Global keys are `accent`, `lightMode`, `coverWidth`, `showReaderProgress`, `keepScreenAwake`, `panSensitivity`, and `momentumStrength`. Per-comic keys are `zoom`, `fit`, `crop`, `keepZoom`, `coverPage`, `rtl`, and `spreads`; these are nested under each portable comic record rather than coupled to its old URI. `fit` stores PAGE/WIDTH/HEIGHT, and `coverPage` is zero-based. Folder selection and SAF grants, unrelated preferences, cache contents, private keys and original files are excluded.

Import rejects an unsupported kind/version, malformed UTF-8, truncated/trailing content, nesting beyond 24 levels, oversized documents, invalid setting types/ranges, invalid page metadata, duplicate records/bookmarks/memberships, and missing collection references before repository writes. Additional ceilings are 10,000 comic records, 1,000 collections, 100,000 bookmarks total, and page indices/counts up to 1,000,000. Original URI and identity strings are bounded. Export goes through the same validation.

A matching URI is accepted only with the same title, folder path, and case-normalized archive format. Changed URIs require a unique identity on both sides. Conflicting targets and ambiguous identities stay pending. Database version 2 adds `backup_pending` and `current_scan` without replacing or dropping version-one data. The pending table retains each complete original record for future scans and subsequent backup exports; an import made before library selection is deferred even when a stale catalog exists and does not create phantom library entries. Current-scan snapshots prevent historical rows from causing incorrect URI matching. Each successful scan also relocates existing state across changed SAF URIs using the previous active scan, including explicit progress/favorite resets and settings removed to restore defaults. Legacy progress fallback preferences stay coherent with imported/reset database state. If a provider reuses the same URI for a different identity, the former book is retained pending and the replacement starts with clean reading state. Related stale URI aliases are omitted from an export when a unique current location exists; unrelated historical entries remain included.

All database changes for an import or scan are transactional. Imports preserve unrelated comics and collections; bookmarks and memberships are unioned. SAF relocation instead replaces associations from the latest active location, so bookmarks and memberships removed there do not reappear from an older URI alias; collection definitions and other comics remain intact. Explicit imported progress, favorite/finished state, and supplied whitelisted preferences replace those values on matched comics. Scanned metadata and existing `added_at` values are retained. Newly discovered scan entries use the actual discovery time rather than file modification time. Settings commit failure rolls back database changes and restores previous preference values. SQLite and SharedPreferences are separate stores, so abrupt process termination between their final commits is a platform-level atomicity limit; ordinary exceptions and commit failures are handled.

- `LibraryBackupCodecTest`: complete round trip, empty collections, corrupt/truncated/trailing/versioned input, malformed UTF-8, size/nesting bounds, strict settings and metadata validation, duplicate rejection, settings whitelist, unique portable URI remapping, ambiguity on either side, and reused URI safety.
- `LibraryBackupInstrumentedTest`: isolated on-disk SQLite/prefs coverage for deferred import and export, next-scan remapping, bookmark/collection merges and unrelated-state retention, all-before-write validation, ambiguous/reused URIs, repeated SAF relocation and discovery timestamps, resets and removed bookmarks/memberships when returning to an earlier URI, recycled document-ID isolation and deferred recovery, explicit no-folder deferral despite stale DB rows, reading-direction/spread remapping, preference-commit rollback, and nondestructive version-one migration.
