# PanelFlow 0.6.5-beta

[Download the signed beta APK](https://github.com/ahmeddangerman/Panel-Fold/raw/refs/heads/main/releases/panelflow-0.6.5-beta.apk)

SHA-256: `f6a4085a2ae85bc2a9b8a70fc34f745c6fef0638d8badb8ec5cd6a6ef430354e`

- Add multiple comic folders in Settings. Existing single-folder selections are kept automatically.
- View, refresh, and remove selected folders. The library scan combines all selected roots before updating the shelf.
- Choosing a folder returns to the main Library screen and clears the prior search and filter.
- If one selected folder cannot be read, comics from it remain on the shelf while the app reports the access issue; a partial scan will not replace the complete library snapshot.

Verification: Kotlin compilation and release APK build passed. APK v2/v3 signing verification passed. No Android tablet or emulator is connected, so folder picker behavior still needs confirmation on the MatePad.
