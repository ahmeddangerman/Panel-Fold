- Open nested ZIP/CBZ and RAR/CBR archives. Their pages appear with the outer archive in natural path order.
- Stage embedded archives on private disk storage, including a native RAR-to-file path that avoids holding whole embedded RAR files in memory.
- Limit recursive nesting to three levels and total expanded nested archive data to 2 GiB; retain the existing page-size and RAR dictionary safeguards.

Verification: all 152 JVM unit tests pass; Android test sources compile; native libraries compile for arm64-v8a, armeabi-v7a, x86 and x86_64; the host UnRAR regression probes pass, including streaming extraction to disk. Instrumented tests could not be run because no Android device or emulator is attached. MatePad / HarmonyOS playback still needs on-device verification.
