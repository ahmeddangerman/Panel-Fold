# PanelFlow 0.6.4-beta

[Download the signed beta APK](https://github.com/ahmeddangerman/Panel-Fold/raw/refs/heads/main/releases/panelflow-0.6.4-beta.apk)

SHA-256: `74bdf41638c960204ece849f159a2f537618909a8dd541c4e8333906e4616e2f`

- Fixed the moving-page renderer omitting high-detail tiles and falling back to previews during every turn.
- Replaced viewport-wide delayed decoding with a fixed-grid, byte-bounded detail cache. A continuous worker completes and publishes tiles while the finger moves, retains them across page changes, and prefetches neighboring viewports at consistent quality.
- Replaced the decorative corner triangle with a geometric corner fold: the page face stays stationary, the lifted paper reflects across a crease controlled by both finger coordinates, and the next/previous page appears underneath. All four corners work, with RTL selecting the appropriate neighboring page. Reversing a pull returns the paper smoothly; finishing moves it fully out of view before committing the page.
- Fixed vertical reading turning at the wrong zoomed image edge.

Verification: all 146 JVM tests pass. The Android gesture/screenshot test APK and signed release APK build successfully. Debug lint reports 0 errors, 7 existing warnings and 1 informational item. APK v2/v3 signatures and 16 KiB ZIP alignment verify.

No Android tablet or emulator is connected to the workspace, so actual touch and Canvas screenshot regressions require device execution. A newly opened or uncached region still requires decoding; available source resolution and the bounded memory cache remain practical limits.
