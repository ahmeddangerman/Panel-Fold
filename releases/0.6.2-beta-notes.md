# PanelFlow 0.6.2-beta

This release updates the app name to **PanelFlow** and adds the PolyForm Noncommercial 1.0.0 license for original project code. Third-party components remain under their included licenses.

It carries forward the 0.6.1-beta reader, archive, library, backup, zoom, and gesture improvements. The Android application ID remains `dev.tabletcomics`, so this build is an update to the existing installation.

The release APK is signed with the existing legacy-to-current certificate lineage for installation updates across supported Android versions. It targets Android API 35 and supports Android API 26 and newer. HarmonyOS and physical MatePad installation have not been verified.

This is a beta release. The 125 JVM tests and build/lint checks from 0.6.1 are documented in the [stabilization results](../docs/beta-stabilization-results.md); this branding/version update was rebuilt as a release APK.
