# Tablet Comics 0.6.1-beta

Audit stabilization and reading tools release. See the [full results](../docs/beta-stabilization-results.md).

Fixed tile and zoom geometry, original source lifetimes, swipe loading/end handling, collection navigation and scroll restoration, stale thumbnails, progress ordering, and solid RAR cursor/cancellation.

Added portable metadata backups, per-comic fit/crop/keep-zoom controls, adjustable pan and momentum, and cover selection/retry/cache tools.

125 JVM tests pass. Debug, release and test APK builds pass; lint has no errors. The 23 Android instrumentation cases are compiled but not device-executed. The signed APK includes the recovered legacy-to-current certificate lineage and packaged 16 KiB-aligned 64-bit libraries.

Still beta: physical MatePad validation remains.
